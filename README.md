# TorqTrace

TorqTrace es una aplicación orientada a talleres mecánicos y propietarios de vehículos, diseñada para registrar mantenimientos, gestionar historiales de service y consultar fallas frecuentes de distintos modelos de automóviles.

El sistema permite centralizar información sobre reparaciones, repuestos y mantenimientos realizados en distintos talleres, facilitando tanto la gestión interna de los mecánicos como la consulta de antecedentes por parte de futuros compradores de vehículos.

---

## Funcionalidades principales

### Usuarios
- Gestión de perfil de usuario
- Registro y administración de vehículos
- Consulta de historial de mantenimiento
- Visualización de fallas comunes por modelo
- Consulta de repuestos más reemplazados
- Recomendaciones de mantenimiento
- Visualización de presupuestos asociados

### Talleres / Empleados
- Gestión de clientes
- Registro de vehículos
- Gestión de repuestos y stock
- Generación de presupuestos
- Registro de trabajos realizados
- Asociación de repuestos a reparaciones
- Historial de trabajos por cliente o vehículo
